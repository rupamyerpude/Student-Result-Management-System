# Result Management System (Python)

A desktop-based Result Management System developed using Python to manage student, course, and result data efficiently through a simple graphical interface.

---

## Features
- Student and course management
- Result entry and automatic calculation
- View and search student results
- SQLite-based persistent data storage
- Tkinter-based GUI dashboard

---

## Technologies Used
- Python  
- Tkinter (GUI)  
- SQLite3 (Database)  
- Object-Oriented Programming (OOP)
